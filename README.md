# Distributed Online Gaming Platform

A distributed client-server gaming platform developed in Java with an Android client.

The system uses multiple servers to process user requests and communicate through TCP sockets.

## Project Structure

The project contains:

- Android client
- Master server
- Worker servers
- Reducer
- Secure Random Generator
- Configuration files for distributed execution

## About

This project was developed as part of university coursework to practice distributed systems, client-server communication and concurrent programming.
